The prompts that make it look easy.

These are the three “finish line” prompts for Tabfair. They read clean, because the messy part already happened. Your mileage may vary if you use this, and my guess is you will still have to reiterate.

Looking back
Reference only
Compressed output

Prompt 1

Core App + Edge Cases

"Build a 4-step bill splitter: 1) Subtotal/Tax input, 2) Tip (pre/post-tax toggle), 3) Split type (even/custom), 4) Results. Include: multi-currency support with persistence, editable people count, and custom splits by amount OR percentage. Critical: When dividing unevenly, distribute leftover cents (0.01 increments) to the first N people—never show a 'remaining' amount."

The “leftover cents” rule is the kind of thing that took real time to get right — but in a prompt it’s just one sentence.

Prompt 2

Pro Features + Rounding

"Add Pro tier (product ID 'tabfairpro') gating: saved preferences, advanced rounding modes (up, nearest-half, nearest-whole). Rounding surplus goes to tip, not bill total. Label clearly as 'Round tip UP to whole [currency unit]'."

The key detail here: rounding “surplus” goes to the tip — not the bill total — so totals stay honest and predictable.

Prompt 3

Native + Contacts

"Add Capacitor contacts picker for naming splits. Prevent duplicates: case-insensitive check against existing names. All toast notifications must be position: 'top-center' for mobile visibility."

Small UX stuff like “top-center toasts” sounds trivial until you’re trying to see them on an actual phone.

Note

What these prompts don’t show

If you copied these, you’d still run into the same walls of platform issues, UI decisions, edge cases, and the “almost there, but not quite” fixes that don’t fit neatly into a prompt.
